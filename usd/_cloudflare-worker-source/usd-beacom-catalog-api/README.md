# USD Beacom catalog API

## Provenance

This README and all source code in this Worker directory were initially
generated by OpenAI Codex on August 12, 2026, at the direction of the
repository owner. The implementation was based on live testing of the public
SDBOR Banner course-search interface. It is an independent, unofficial tool
and is not authored, reviewed, endorsed, or supported by SDBOR, USD, Ellucian,
or Cloudflare. Because the upstream interface may change, the generated code
should be reviewed and retested before it is reused or redeployed.

This Cloudflare Worker relays two narrowly defined, anonymous queries to the
public SDBOR Banner course-search application:

- `GET /api/terms` returns Banner's available semester list.
- `GET /api/semester?term=202680` returns the first 500 USD sections in the
  Beacom subject prefixes for the selected term.

The Worker establishes a fresh anonymous Banner session for every cache miss,
selects the requested term, and carries Banner's cookies between requests. It
is intentionally not a general-purpose proxy. Responses are briefly cached to
reduce repeated traffic to SDBOR.

The static frontend is `/usd/beacom-catalog.html` in the site repository.

## Commands

```text
npm install
npm run check
npm run dev
npm run deploy
```

The browser origin policy permits `https://rmwinslow.github.io`, HTTPS origins
on `rmwinslow.com` and its subdomains, and explicit localhost development
origins. It also permits the `null` origin used when the HTML page is opened
directly from a local `file://` path. The latter is acceptable because this API
contains only public course listings and no credentials or private data.
